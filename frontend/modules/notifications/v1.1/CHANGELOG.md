# Notifications Module Changelog

Versioning is tracked separately for this module under `frontend/modules/notifications/v1.1/`.

## v1.1
- Created modular, high-fidelity lockscreen-style notification feeds.
- Added visual `NotificationCard` mimicking physical phone lockscreen bubbles with glassmorphism and real-time stamps.
- Added absolute-positioned dynamic `InAppBanner` which slides in from the top of the viewport and auto-fades / swipable to dismiss.
- Added filterable `NotificationsFeed` component suitable for Admin, Employee, and Client dashboards.
