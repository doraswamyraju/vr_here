# Dynamic Service Page Editor Module Changelog

- **Initial Setup**: Established initial modular split under `v1.1`.
- **API service hooks**: Added `serviceConfigApi.js` supporting dynamic GET/POST mapping for customization records.

- **Section node builders**: Forms to seamlessly customize all service fields including packages features, reviews ratings, step indexes, trust logos.
